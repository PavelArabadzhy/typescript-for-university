# Практична робота №1

Цей репозиторій створений для виконання практичної роботи з дисципліни  
**"Спеціальні мови програмування (TypeScript)"**.

У проєкті налаштовано базове оточення для роботи з TypeScript:
- створено конфігураційний файл `tsconfig.json`;
- додано вихідну директорію `src`;
- реалізовано простий приклад коду з використанням базових типів TypeScript;
- налаштовано компіляцію у директорію `dist`.

Робота виконана у навчальних цілях.
