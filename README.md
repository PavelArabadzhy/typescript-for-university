# Практична робота №5
**Тема:** Розробка базових компонентів інтернет-магазину з використанням Generic типів у TypeScript  

## Виконано у межах практичної роботи:

### 1. Створено типи товарів
- **BaseProduct** — базовий тип із полями `id`, `name`, `price` та додатковими опційними властивостями.
- **Electronics**, **Clothing**, **Book** — специфічні типи, що розширюють BaseProduct та містять власні категорії й додаткові поля.

---

### 2. Реалізовано generic-функції
- **findProduct\<T\>** — пошук товару за його `id`.
- **filterByPrice\<T\>** — фільтрація товарів за максимальною ціною.
- Обидві функції типобезпечні та містять перевірку коректності аргументів.

---

### 3. Логіка кошика
- Тип **CartItem\<T\>**.
- **addToCart\<T\>** — додає товар у кошик:
    - збільшує кількість, якщо товар уже є;
    - не додає некоректні дані;
    - працює імутабельно.
- **calculateTotal\<T\>** — рахує загальну суму всіх товарів у кошику.

---

### 4. Тестові дані та демонстрація
- Створено тестові масиви товарів:
    - електроніка,
    - одяг,
    - книги.
- Продемонстровано роботу всіх функцій:
    - пошук,
    - фільтрація,
    - додавання товарів,
    - підрахунок total,
    - обробка помилкових випадків (undefined товар, порожній масив, некоректні значення).
