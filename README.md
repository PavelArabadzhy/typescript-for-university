## Практична робота №2
Гілка: **feature/tsconfig**

У рамках другої практичної роботи виконано:

- Додано HTML/CSS шаблон сайту.
- Підключено та налаштовано TypeScript.
- У файлі `src/main.ts` реалізовано інтерактивність:
    - модальне вікно (відкриття/закриття),
    - обробка подій `click` і `scroll`,
    - анімація блоку `.hero`,
    - завантаження даних через `fetch` із `https://jsonplaceholder.typicode.com/`,
    - кнопка "Завантажити ще" для підвантаження постів.
- Код TypeScript компілюється у `dist/main.js`.
- У `index.html` підключено згенерований скрипт.
- Гілку `feature/tsconfig` опубліковано через GitHub Pages.
