# Практична робота №6
**Тема:** TypeScript & Enum

У роботі реалізовано:

- Enum-и: StudentStatus, CourseType, Semester, GradeValue, Faculty.
- Інтерфейси Student, Course, Grade.
- Клас `UniversityManagementSystem` з методами:
    - enrollStudent
    - registerForCourse
    - setGrade
    - updateStudentStatus
    - getStudentsByFaculty
    - getStudentGrades
    - getAvailableCourses
    - calculateAverageGrade
    - getExcellentStudentsByFaculty
- Додано всі перевірки: статус студента, наявність місць на курсі, реєстрація перед виставленням оцінки.
- Наприкінці файлу містяться тестові виклики для перевірки роботи.
